🌐 كورس تصميم وتطوير المواقع الإلكترونية الاحترافية بالذكاء الاصطناعي

تبني موقعك الاحترافي بـ Claude Code، خطوة بخطوة

نظام الكورس:
  • سعر الجلسة: 15,000 دينار
  • مدة الجلسة: ساعة إلى ساعة ونص
  • ما ننتقل للجلسة اللي بعدها إلا بعد ما تكمل مهام الجلسة السابقة
  • الكورس ينتهي بعد ما تكمل كل الجلسات
  • 🎁 هدية: موقع إلكتروني باسمك تعرض بيه أعمالك

الجلسة 1: تجهيز جهازك والانطلاقة 🚀

  • نثبت كل البرامج اللي تحتاجها خطوة بخطوة
  • نشغّل Claude Code ونفهم شلون يشتغل
  • نشغّل أول موقع على جهازك ونشوفه بالمتصفح وعلى موبايلك
  • تسوي حساب على GitHub حتى تحفظ شغلك بأمان
المهام:
✅ كل البرامج مثبتة وشغالة
✅ أول صفحة تجريبية تشتغل بالمتصفح

الجلسة 2: شلون تحچي ويا الذكاء الاصطناعي 🧠

  • سر كتابة الطلب الصحيح حتى Claude يفهمك من أول مرة
  • أخطاء شائعة تخلي الذكاء الاصطناعي يخرب شغلك وشلون تتجنبها
  • شلون تعطي Claude "دستور" لمشروعك حتى يلتزم بيه دائماً
  • نحول فكرة موقعك لخطة واضحة: الصفحات، الأقسام، والجمهور
المهام:
✅ تكتب فكرة موقعك بالتفصيل
✅ خطة الموقع جاهزة ومراجعة

الجلسة 3: بناء صفحات الموقع 🧩

  • Claude يبني الصفحات وإنت توجهه
  • الصفحة الرئيسية، من نحن، الخدمات، المعرض، وتواصل ويانا
  • قائمة تنقل احترافية للكمبيوتر والموبايل
  • شلون ترجع خطوة لورا إذا Claude خرب شي
المهام:
✅ كل صفحات الموقع موجودة وتتنقل بينها

الجلسة 4: التصميم الاحترافي 🎨

  • اختيار ألوان وخطوط تعطي هوية لموقعك
  • دعم اللغة العربية بشكل كامل (من اليمين لليسار)
  • الوضع الليلي وحركات خفيفة تخلي الموقع حي
  • شلون تعطي Claude صورة تصميم ويبنيه لك نفسه
  • الموقع يبين مرتب على الموبايل والتابلت والكمبيوتر
المهام:
✅ ترسل سكرين شوت لكل الصفحات بشكلها النهائي

الجلسة 5: البيانات والحسابات 🔐

  • ربط الموقع بقاعدة بيانات أونلاين مجانية
  • تسجيل دخول بالإيميل أو حساب Google
  • لوحة تحكم (Dashboard) تضيف وتعدل بيها المحتوى بدون كود
  • فورم تواصل وطلبات توصلك مباشرة
المهام:
✅ تسجيل الدخول شغال
✅ الإضافة والتعديل والحذف شغالين والبيانات محفوظة

الجلسة 6: المزايا المتقدمة ⚡

  • رفع الصور والملفات
  • زر واتساب وربط صفحات التواصل الاجتماعي
  • إضافة ذكاء اصطناعي داخل موقعك (مثل مساعد أو شات)
  • شلون تخلي Claude يلگه الأخطاء ويصلحها بنفسه
المهام:
✅ إضافة ميزتين متقدمتين على الأقل
✅ تجرب الموقع عند شخصين غيرك وتصلح ملاحظاتهم

الجلسة 7: التجهيز للنشر 🛠️

  • أيقونة الموقع وصورة المشاركة لما ينرسل الرابط
  • ظهور الموقع بنتائج Google (SEO)
  • سرعة التحميل وفحص الموقع على كل الأجهزة
  • فحص أخير قبل ما ينزل للناس
المهام:
✅ الموقع سريع ويشتغل على كل الأجهزة
✅ ترسل الموقع لـ 3 أشخاص يجربوه

الجلسة 8: النشر والتسليم 🏆

  • رفع الموقع على استضافة ونشره أونلاين خطوة بخطوة
  • ربط دومين (اسم موقع) خاص بيك
  • شلون تحدّث الموقع بعد النشر بضغطة وحدة
  • نضيف مشروعك لموقعك الشخصي (الهدية)
  • شلون تكمل وتطوّر مواقعك بروحك بعد الكورس
المهام:
✅ الموقع منشور أونلاين وبيه رابط حقيقي
✅ موقعك الشخصي جاهز وبيه مشروعك
