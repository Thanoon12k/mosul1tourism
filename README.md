# حارث فراس — السياحة في الموصل

موقع ثنائي اللغة (العربية والإنكليزية) مبني بـ Flask، ويضم:

- ثلاث مجموعات خدمات: الجولات السياحية، الحج والعمرة، وحجز الفنادق.
- عرض الرحلة الأحدث من صفحة حارث.
- تسعة معالم موصلية بصور حقيقية ومصادر موثقة.
- دليل أولي يضم خمسة فنادق في الموصل بصورها وتصنيفاتها وأسعارها التقريبية.
- 24 صورة وبوستر من رحلات حارث.
- روابط واتساب برسائل جاهزة لكل خدمة.

## التشغيل على Windows

انقر مرتين على start.bat، أو نفّذ:

~~~powershell
.\run.ps1
~~~

بعدها افتح:

http://127.0.0.1:5000

فحص الخادم:

http://127.0.0.1:5000/health

## PythonAnywhere

الحساب المستهدف: harith1mosul1tourist

المجلد المقترح على الخادم:

/home/harith1mosul1tourist/harthwebsite

بعد رفع الملفات:

1. أنشئ بيئة افتراضية وثبّت requirements.txt.
2. اجعل Source code و Working directory على المجلد أعلاه.
3. اجعل ملف WSGI يستورد application من pythonanywhere_wsgi.py.
4. اربط مجلد /static/ مع /home/harith1mosul1tourist/harthwebsite/static.
5. اضغط Reload من صفحة Web.

تفاصيل نسب الصور موجودة في ATTRIBUTIONS.md وتظهر أيضاً في ذيل الموقع.
